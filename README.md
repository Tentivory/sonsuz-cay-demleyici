# Sonsuz Çay Demleyici

Bu proje, insanlığın en büyük sorununu çözmek için yaratıldı: **Çayın asla bitmemesi**.

## Nasıl Çalışır?

```bash
python cay_demle.py
```

Program başladıktan sonra çay demlenmeye başlar. Yüzde 99.999'a kadar gelir, sonra birdenbire "daha demlenmeli" diye karar verip baştan başlar. Çay asla içilmeye hazır olmaz. Bu bir özelliktir, bug değil.

## Özellikler

- Sonsuz demleme süresi
- Rastgele "biraz daha demlensin" kararları
- Çayın asla soğumaması (sanal olarak)
- Kullanıcıyı çay beklerken varoluşsal krize sokma
- Gizli bir mesaj içerir (bulabilirsen)

## Uyarı

Bu programı çalıştırdıktan sonra gerçek çay demlemek istemeyebilirsiniz. Çünkü gerçek çay biter. Bu ise bitmez.

## Lisans

Çay içen herkes için ücretsiz. Çay içmeyenler için ücretli (ama yine de çalışır).
